Ce projet est utilisé dans le but d\textquotesingle{}enregistrer de manière automatique une scene à l\textquotesingle{}aide d\textquotesingle{}une caméra de profondeur.

Cela permet d\textquotesingle{}extraire le squelette d\textquotesingle{}une personne dans une sequence, de les stocker dans une base de données Influx\+DB et d\textquotesingle{}analyser la démarche de la personne.

Les caractéristiques extraites sont\+:
\begin{DoxyItemize}
\item La vitesse de la marche,
\item La longueur des pas,
\item La largeur des pas,
\item Le ratio \char`\"{}double-\/support\char`\"{},
\item Le ratio \char`\"{}stance/swing\char`\"{} sur chaque jambe.
\end{DoxyItemize}

Un Raspberry Pi s\textquotesingle{}occupe d\textquotesingle{}enregistrer les signaux de plusieurs capteurs sur lequel il est branché, et de stocker cela dans une base de données Influx\+DB.

Avec les données des capteurs qui vont servir d\textquotesingle{}entrée et les caractéristiques de la caméra pour la \char`\"{}verité terrain\char`\"{}, nous pouvons entrainer des réseaux de neurones.

Plusieurs types de réseaux de neurones sont proposés ici\+:
\begin{DoxyItemize}
\item Un réseau de type MLP (Multi-\/\+Layer Perceptron)
\item Des réseaux convolutifs\+:
\begin{DoxyItemize}
\item CNN (Convolutional Neural Network) \char`\"{}classique\char`\"{}
\item Res\+Net (CNN avec l\textquotesingle{}utilisation de \char`\"{}résidus\char`\"{})
\item Modèles prédéfinis de type Alex\+Net, Google\+Net, VGG, etc...
\end{DoxyItemize}
