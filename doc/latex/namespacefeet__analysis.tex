Get the walking speed with the average of the movement of the hips. 

\begin{DoxyAttention}{Attention}
This function uses the average of the velocities recorded on the hips. Another way to estimate this with a higher accuracy when knowing that the person is walking in a linear path would be to compute the difference of coordinate at the beginning of the sequence and at the end of the sequence. This is a more generic but less accurate way to compute it. It is, still, a pretty good estimation. 
\end{DoxyAttention}
