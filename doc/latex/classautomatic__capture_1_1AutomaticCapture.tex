\doxysubsection{Detailed Description}
The Automatic capture will use the output from the skeleton tracker to start or not the recording of a sequence. 

It will check if a person is present on screen using threads to avoid slowing down the program. The \textquotesingle{}latency\textquotesingle{} parameter is the elapsed time in seconds between two checks
