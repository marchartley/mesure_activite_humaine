\doxysubsection{Detailed Description}
This small script enables us to display the skeleton in 3D of the last walking stored in the database. 

With this script you will discover that the Aruco box doesn\textquotesingle{}t align things very well... A straight walk in the corridor will result in a small deviation on the X-\/axis. Remember that if you want to distinguish walks on the \char`\"{}\+West\char`\"{}, \char`\"{}\+Center\char`\"{} and \char`\"{}\+East\char`\"{}, that you cannot separate only with the X-\/axis position of the person, but you might have to think about a small equation or, if motivated, using a SVM.
