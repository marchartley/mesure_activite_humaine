Detailed Description

This file regroup multiple functions that are useful when you want to convert positions from a referential into another.

For example when using the Aruco box, it allows to easily switch from the 2D coordinate of a pixel into the 3D coordinate relative to the box.

Parameters

idsList of the IDs of the markers detected on screen
depth_frameThe depth frame coming from the camera
pipelineThe RealSense pipeline from the camera
Returns
A tuple containing:
  • The center of the new referential
  • A Dict object with the position of each axis {'x': position_x, 'y': position_y, 'z': position_z}
  • The list of each center of markers
  • The list of each axis computed by each markers
Note
The Aruco cube is using 6 Aruco tags. The camera can see at max 3 markers at the time, we want to get the maximum of precision on the axis by using the average of all markers seen

Compute the 3D coordinates from a point that was in the camera origin to another origin (ex: Aruco box)

Parameters
coordThe 3D coordinates of a point from the camera
new_origin_coordThe 3D coordinates of the origin of the new referential
new_x_axis_coordThe 3D coordinates of the point (1, 0, 0) in the new referential
new_y_axis_coordThe 3D coordinates of the point (0, 1, 0) in the new referential
new_z_axis_coordThe 3D coordinates of the point (0, 0, 1) in the new referential
scaleThe scale of the new referential
Returns
The 3D coordinates of the original point in the new referential
Note
The scale is useful if the "new_(x|y|z)_axis_coord" are not at 1m from the origin. For example, the Aruco box has markers of size 0.21m, so you can take the corners of the marker as axis coords and apply a scale of 0.21 to compensate.
