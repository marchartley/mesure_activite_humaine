Small utility function to check if two lines in a plane are intersecting.

This can be useful when checking if the two legs of the person are crossing.

Parameters
start1(x, y) coordinates of the beginning of the first line
end1(x, y) coordinates of the ending of the first line
start2(x, y) coordinates of the beginning of the second line
end2(x, y) coordinates of the ending of the second line
Returns
A boolean set to True if the two lines are colliding/intersecting, False otherwise.

◆ get_body_orientation()

np.ndarray get_body_orientation (   self)

Get a vector representing the orientation of the person in the 3D environment as a Euler rotation vector.

Remarks
This algorithm uses the cross product between the lines drawn between the shoulders and the hips and do a mean of the 4 results. At least 3 of the joints are needed to compute the orientation
Returns
An Euler rotation vector

Convert the coordinates of the skeleton into a JSON format that can be easily used to import it in the database.

Parameters
ref_centerThe coordinates (from the camera) of the center of the referential. By default it's (0, 0, 0) => camera referential, but it can be changed to use the Aruco box's referential
ref_xThe coordinates (from the camera) of the point (1, 0, 0) of the referential
ref_yThe coordinates (from the camera) of the point (0, 1, 0) of the referential
ref_zThe coordinates (from the camera) of the point (0, 0, 1) of the referential
scaleThe scale used on the 3 axis (ref_x, ref_y, ref_z). For instance, if the X-axis is computed from the borders of the Aruco box (which is 21cm long), you need to provide a scale of 0.21.
