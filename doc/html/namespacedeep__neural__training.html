◆ precompute_morlet_transforms()

Dict deep_neural_training.precompute_morlet_transforms ( pd.DataFrame  raw_data,
str   pir_transforms_filename = 'all_pirs_transformed.data',
Union[str, bool]   output_filename = True 
)

Function that compute all the Continuous Wavelet Transforms of the dataset and store them in a Pickle file.

Parameters
raw_dataA DataFrame containing all the data of the dataset. This might be the content of 'gait_values.csv'
pir_transforms_filenameThe name of the file in which you want to save the CWT data
output_filenameCan be a boolean set to True to effectively save the CWT data or False to not save the file and just return the results in the script.
Can also be a string if you want to save the CWT data in another file.
Returns
The dataset values containing the Continuous Wavelet Transform of each sensor and the ground truth of all walking parameters.
Note
If the file "pir_transform_filename" already exists, none of the sequences contained inside is computed again. For a fresh start (your CWT computation has been modified, there was error on the data or else), you must delete the previous file in order to compute completely all the sequences
