Parameters
input_sizeWidth (and height) of the images to process
output_sizeNumber of neurons at the end of the linear part of the model
kernel_sizeThe size of the kernel used during the convolutions
number_of_filtersThe number of filters at the end of a convolution. In our program this number doesn't vary after each convolution, but you could program to do so if you have some patience.
number_of_layersNumber of times we do a Convolution+Max pooling in the network
hidden_cellsThe number of hidden neurons on the dense part of the network. If integer, it makes a unique hidden layer with this number of neurons but if you pass an array of integers, it will make multiple hidden layers with the desired number of neurons
dropoutDefines if a dropout is applied at the beginning of the dense part of the network. If True, it will apply a 0.5 dropout but you can pass a float instead to define yourself the desired value. If you want to take the time to put dropouts somewhere else, feel free to program it
use_concat_pirDefines if you want to have one tensor containing the 4 sensors' data or whever you prefer having one unique process for each sensor. (I think it doesn't change much, maybe keep it to True)
number_of_conv_per_layerNumber of convolution done before each Max Pooling
pure_CNNDefines if you prefer a classic CNN with a Dense Layer using each pixel of each filter at the end of the convolutional part as neurons, or if you want to apply a Global Average pooling to reduce greatly the size of the dense layers. (without "pure_CNN", the number of neurons is (input_size / 2^number_of_layers) * number_of_filters, while with "pure_CNN", the number of neurons is equal to number_of_filters.) With a bit more of programming, you can increase the number of filters during the process to improve the network.
layer_reluActivation function used after each convolution layer.
reduce_last_convIf greater than 0, apply a last convolution with "reduce_last_conv" filters to reduce the number of neurons in the dense part.
using_batch_normSet to True if you want a Batch Normalization before each convolution.
